# テスターの回答（原文）

三択診断のテスト協力モード（`?fb=1#three`）で集めた回答テキストの原文です。持ち主の判断で、公開リポジトリに置いています（[決定記録 D7](../../docs/decisions.md)）。

- 中身は参加者コード（ニックネーム）と回答ログ・振り返りの答えだけです。自由記述は全員空で、連絡先は含まれていません（2026-10-16 に確認）
- 1ファイル＝1人です。最後の行（`16DFB1|crc|JSON|END`）が機械用で、CRC で途中切れや書き換わりを検出します
- 読み方と集計：ファイルの中身をまとめて [admin.html](../../admin.html) に貼ります。参加者一覧、領域ごとの照合、ブラインド比較、カード評価、設問ごとの表、見直し候補、今のロジックでの再採点が出ます。形式は [docs/feedback-spec.md](../../docs/feedback-spec.md) にあります
- Node から読む場合は `js/feedback_format.js` の `decodeAll(text)`、または `js/admin/aggregate.js` の `analyze(text)` を使います
- 結果のまとめは [docs/test-results.md](../../docs/test-results.md)、自動集計は [summary-2026-10-16.md](summary-2026-10-16.md) にあります

## 新しい回答を足すとき

1. 届いたテキストをそのまま `v1/` か `v2/`（設問の版ごと）に `<コードのローマ字>.txt` で保存します。同じ人の受け直しは `<コード>-2.txt` のように分けます
2. 上の一覧に1行足します
3. `admin.html` で集計し直し、必要なら `summary-<日付>.md` を作り直して [docs/test-results.md](../../docs/test-results.md) を更新します
4. 自由記述に本名・連絡先・第三者が分かる内容があれば、入れる前に持ち主に確認します
