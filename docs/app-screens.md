## 4. 画面ごとの中身

### 4.1 ホーム（画像1・2）
- 上：小さな英字「HOME」を細い横線ではさむ。見出し「今日はこちらから」。3行の文「心が少し軽くなる、／あなたのための診断と相談。／いつでも、ここにいます。」。右に大きな絵（仮：傾向の絵。背景になじむよう縁をぼかす）
- **相談の欄（上）**：見出し「｜相談」、右に小さく「今の気持ちを整理する」。カード1枚（絵＋「今の気持ちを自由に書いて／アドバイスをもらえます。」＋丸い → ボタン）。押すと `#consult`
- **診断の欄（下）**。状態で中身を変える
  - 診断前：見出し「｜診断」。カード（絵＋小さな印「まだ診断していません」＋大きく「診断をはじめる」＋「8〜10分」＋ →）。押すと `#diagnose`
  - 途中（1問以上答えた）：「途中まで答えています（n問）」＋「続きから答える」→ 質問へ。小さく「最初からやり直す」
  - 診断後（画像2）：見出し「｜診断結果」、右に「もっとあなたを見る ›」（→ `#result`）。カード：小さく「あなたの主軸」、大きく**主軸の見出し**（パターンの headline）、その下に1〜2行（パターンの one）、区切り線、「主な傾向」と点つきの3行（強く出ている傾向。点の色は A 側＝くすんだ赤、B 側＝灰青）、丸い → ボタン（結果へ）。カードの下に「⟳ もう一度診断する ›」の行（画像1の形）
  - **相性の丸は出さない**（相手の診断が無いと出せない。決定 U29 の4）
- 下のタブ：ホーム（家）／履歴（紙）／マイページ（人）。いまの画面は、くすんだ赤の塗りの家と赤い文字

### 4.2 診断の開始画面（画像なし）
- 上：「←」と、中央に細い横線ではさんだ題「診断」
- 見出しと説明は今の開始画面の文（「左か、右か。迷ったら問題を変える」、2つの文から自分に近い方を選ぶ、問題を変えるは1問につき2回まで、64〜80問・8〜10分ほど）
- 主ボタン「診断をはじめる →」。途中の回答があれば「続きから答える」と「最初からやり直す」
- 可変モード（決めきれないところだけ追加で聞く）は、いつもオン。設問は既定の v3

### 4.3 診断の質問（画像3）
- 上：「←」（ホームへ。回答は保存されたまま）、中央に「診断」、右に「40 / 64」（答えた数 / 今の予定の数。追加の質問で予定の数は最大80まで増える）
- 細い進み具合の棒（くすんだ赤、残りは薄いベージュ）
- 小さな灰色の文：W の問は「この場面で」、X の問は「別々の場面の行動を比べて」
- 大きな明朝：W は場面の文（stem）＋その下に「取りやすいのはどちら？」（prompt）、X は「より自分らしいのはどちら？」など prompt
- 回答2枚を縦に並べる（PC でも縦）
  - 上＝左の回答：左にくすんだ赤の丸「←」、縦の細い線、文
  - 下＝右の回答：文、縦の細い線、右に灰青の丸「→」
- スワイプは **C「触った回答だけ」**（U28）：つかんだ回答だけが、その側へだけ動く。回答の外から始めたら向きの側の回答が動く。上＝問題を変える（使い切ったら答えずに進む）、下＝戻る（この2つは問いと回答のまとまりごと動く）。タップでも答えられる。キーボードは ← → Space
- 下：手のアイコンと「← →」、「左右にスワイプするか、／タップで選んでください」。「または」の区切り線。枠だけの丸いボタン「⟳ 問題を変える｜残り2回」（使い切ったら「答えずに進む」）。下線つきの文字リンク「中断して最初の画面へ（回答は保存されています）」
- 練習カード（1問目の前・採点しない）も同じ形。小さく「練習・結果には入りません」
- 追加の質問のとき（W追加・X追加）・差し替えたときの短い案内は、今の画面と同じ文を小さく出す

### 4.4 診断結果（画像6）
- 上：「←」、中央に「診断結果」、右に枠だけの丸いボタン「シェア」（共有のアイコン）
- 見出し「あなたを表す解釈」
- パターンのカード（主軸1＋補強・矛盾・地、合わせて2〜4枚。今の結果と同じ選び方）
  - 左に墨色の太い帯（主軸）。補強などは細い帯や色を変える
  - 上：墨色の丸い印「主軸」と、薄い印「基本解釈・領域1」（パターンの種類と領域）
  - 大きな明朝の見出し（headline）、その下に灰色で領域の名前
  - 区切り線、太字の1〜2行（one）、本文（detail。ゴシック）
  - 薄い箱「👆 違うと思う文があればタップ（もう一度タップで取り消し）」。本文を文ごとに区切り、タップした文に「違う」の印（取り消し線など、色だけに頼らない）
  - 区切り線、「場面例は、自分にありそうかどうかを選んでください」、場面例ごとに「ありそう」「なさそう」の丸い枠のボタン（押した方が塗られる。もう一度で取り消し）

## 6. 作り（ファイルと決まり）

### 6.1 ファイル

```

app/js/main.js              ハッシュで画面を切り替える。各画面は render(root, route) を持ち、片付けの関数を返してよい
app/js/ui.js                小道具（h()、上の題、下のタブ、丸い矢印ボタン、トースト、アイコン）
app/js/local.js             端末の中の記録（§6.3）
app/js/home.js, account.js, history.js, mypage.js
```

### 6.2 使い回す仕組み（**中身の JS は直さない**）
- 診断：`js/ui/three_store.js`（`restore3`・`start3`・`answer3`・`swap3`・`skip3`・`back3`・`practice3`・`practicePending3`・`onChange3`・`store3`）。保存は今の画面と同じキー（`seikaku16:three:v1`）なので、どちらの画面で答えても続きと結果が共通
- スワイプ：`js/ui/swipe.js` の `attachSwipe`（`target`・`allow`）と `js/ui/swipe_variants.js` の `swipePart("c", …)`・`swipeAllows("c", …)`
- 結果の本文：`js/data/patterns*.js`（今の `three.js` の `patternCard` と同じ値）、`js/ui/labels.js`、`js/ui/result.js` の `byRole`、場面例 `js/data/scenes_v2.js`（`three_version.js` の `scenesFor`）
- 傾向の絵：`js/data/type_images.js`（`TYPE_IMAGES`・`isReady`・`heroTendency`・`domainTendencies3`）
- 相談：`poc/card/model.js`（DOM なし）と、その下の `js/consult/`。画面の流れは `poc/card/poc.js` を手本にする
- 理由：Website の試作は、このリポジトリの `js/` をそのまま写して使っている（Website の決定 0177）。中身を変えると、そちらにも影響する

### 6.3 端末の中の記録（`app/js/local.js`。キー `seikaku16:app:v1`）
- `loadRecords()` → `{ items: [...] }`（新しい順）
- `addRecord({ kind: "diagnosis"|"consult", at, title, sub, data })` → id。同じ診断結果は2回足さない
- `removeRecord(id)`、`clearRecords()`
- `getMarks(key)`・`setMarks(key, marks)`：結果の「違う」の印とありそう／なさそう（key は結果ごと）
- localStorage が使えないときも画面は動く（記録しないだけ）。どこにも送らない

## 10. 作ってみて、仕様に足したこと・変えたこと（2026-10-18 持ち主が了承「それ以外はよい」）

| 画面 | 足したこと・変えたこと | 理由 |
| --- | --- | --- |
| ホーム | 相談のカードは絵を上に大きく、題「なんでも相談する」＋画像1の2行 | 相談を主役にするため（§3 の3） |
