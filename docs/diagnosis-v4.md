## 5. 採点（`js/engine4.js`）

- 答えは A＝＋1、B＝−1、判断できない＝null。領域 d ごとに3問（U{d}・P{d}・N{d}）の答えを数える：**n＝答えた数**（判断できないは数えない）、**a＝A の数**、**b＝B の数**
- **share＝A の割合**（a / n を % にして四捨五入：100・67・50・33・0）
- 状態（上から順に最初に合うもの）：

| 条件 | 状態 | 見出し | 本文 |
| --- | --- | --- | --- |
| n＜2 | incomplete | この領域はまだ分かりません | 判断できない問が多いため、この領域は出していません。 |
| b＝0（n＝2 か 3） | A強（`strongA`） | 「A」を選びやすい | {n}問とも「A」を選びました。 |
| a＝0 | B強（`strongB`） | 「B」を選びやすい | {n}問とも「B」を選びました。 |
| a＞b（b＞0） | A寄り（`leanA`） | 「A」寄り | {n}問のうち{a}問で「A」を選びました。 |
| b＞a（a＞0） | B寄り（`leanB`） | 「B」寄り | {n}問のうち{b}問で「B」を選びました。 |
| a＝b | まんなか（`mid`） | どちらか一方には寄らない | 「A」と「B」を同じ数だけ選びました。 |

- A・B は傾向の名前を「」で囲んで入れる（例「「向き合う」寄り」）。言い回しは決めつけない（「〜な人」と言わない）
- **違いの印**（`differentDirections`）：U の答えがあり、P と N の答えが両方あって同じ向きで、U と逆のとき。本文の後ろに「普段の自分と、場面で選んだ行動に違いがありました。」を足す。不正・矛盾・精度の低さの意味ではない。減点しない・追加の問いはしない
- **主軸と補足**：候補は強（A強・B強）と寄り（A寄り・B寄り）の領域。強が先、次に寄り。同じなら答えた数 n が多い方、さらに同じなら領域の番号順。先頭が主軸、次の2つまでが補足（表示の並べ方で、統計的な重要度ではない）
  - 候補が無く、状態の出た領域（まんなか）がある →『今回の回答では、片側に強く寄らない傾向』（`lead: "flat"`）
  - どの領域も incomplete → 総合の見出しを作らない（`lead: "none"`）。「判断できない問が多いため、領域ごとの傾向はまとめていません。分かっている回答だけを出しています。」と、相談への入口
- **組み合わせ（既存の172パターン）はこの版では出さない**（仕様書の「候補がなければ基本結果だけで完結させる」の形）。confidence の数も作らない
- 旧版の勝率・67/39・票の差・0.8 倍は持ち込まない

## 7. 保存（`js/ui/four_store.js`。キー `seikaku16:four:v1`）

```json
{ "schemaVersion": 1, "diagnosisVersion": "v4", "questionBankVersion": "v4-24-dotchi-2026-10-21",
  "questionOrder": ["U1", "P2", "N3", "…24個すべて"],
  "answers": { "U1": { "status": "answered", "value": 1 }, "P2": { "status": "answered", "value": -1 }, "N3": { "status": "unknown", "value": null } },
  "currentIndex": 3, "completed": false }
```

- 未回答＝answers にキーが無い。判断できない＝`status: "unknown"`・`value: null`。この2つを混ぜない
- 読むとき：1・−1 以外の値（NaN・0・2・文字列・形の違う値）は**未回答に戻す**（キーを消す）。版（schemaVersion・diagnosisVersion・questionBankVersion）が違えば読まない。completed は答えから決め直し、currentIndex は最初の未回答より先へ進めない
- **問の版の印を変えたので、U42 の当てはまり度の版で保存した物（`v4-24-2026-10-20`。公開していない試しの物）は読まずに捨てる**（「v4 の診断は無い」として動く。三択の保存には触らない）
- 答えるたびに保存する。読み込み直すと同じ問いから続く
- 結果は保存しない。**読むたび・答えるたびに今の24問の答えから作り直す**（戻って答えを変えても古い結果を使わない）
- 結果の形：`domains`（`picks`〔U・P・N の "A"・"B"・"unknown"・"unanswered"〕・`n`・`a`・`b`・`share`・`state`・`differentDirections`・`missing`）、`primaryDomainId`、`supportingDomainIds`、`lead`（primary・flat・none）、`completeDomainIds`、`counts`、`diagnosisVersion`、`questionBankVersion`
