# 結果の分析を深め、8軸を末尾に戻す（U57）

2026-10-27。持ち主「良くなりました。ただ、人間への分析力がまだ足りていません。より分析して下さい」「きめ細かく」「8軸について旧版のように軸は結果画面の1番下」「旧版の記載が理想」を反映。

## 内容

U55の主軸・クロス・特殊、具体例・長所・提案の構成を維持し、行動の背後で何を求め、どのような循環が生まれやすいかを加える。文章の量だけを増やすために行動を再要約せず、次を各パターンで書き分ける。

- **主軸16傾向**：何に安心を求めるか、何を守るための動きか、同じ行動の別の意味。短所の欄は、長所が裏目に出る境目と、それを日常で見分ける手掛かりへ深める。例：待つ＝信頼して任せる場合／断られることを避け、相手から来るかを試している場合。
- **クロス80パターン**：二つの動きが重なったときの意図と受け取られ方、会話の時間差、働きかけと相手の反応の循環をすべて個別に追記。
- **特殊18パターン**：複数の傾向が重なって、なぜ同じ修復が効きにくくなるかを個別に追記。例：共感を求めて進行も握る→相手が従う→その言葉を自発的でないと感じる。
- **回答に表れたもう一つの面**：24問の2対1では、実際に反対側を選んだ場面と選択肢を引用する。同じ主軸でも、P/Nのどちらで切り替わったかで説明を変える。80問では同じ場面の選択と別領域との比較の向きが違う場合を残す。1領域の反例は画面全体で一度だけ。
- **中間・両方強い・弱い**：単にどれも「柔軟で長所」としない。両方の必要が競合する場合、選び分けている場合、選択肢だけでは分からない場合を区別する。

内面の理由は測定済みの因果として断定せず、回答に重ねて考えられる解釈として書く。相手の反応は条件付きの例であり、相手の診断ではない。育った環境、病名、愛着分類は推定しない。普段と場面の逆転を「理想と本音」「建前」と決めつけない。採点・質問・選ばれるパターン・保存形式・ホームと共有のタイトルは変更しない。心理尺度として精度が上がったと検証したものではなく、結果の解釈と表現を詳しくする変更。

## 8軸の復活

本文・会話例・安全の案内・操作の後、ページ共通の最下部のヘルプリンクの直前に「8つの軸」を置く。分析の途中に一覧を挟まない。

- 80問：旧版の `axesSection` をそのまま使用。各軸の絵・横線・位置・選択割合・強さ・弱め等の印を表示。
- 24問：旧版と同じ絵・横線・位置表示。実際の選択数と割合を表示し、80問の強さスコアは作らない。割合は選択数の比率であることを明示。2問だけ回答した場合、判定できる数がない場合、普段と場面が逆の場合も区別。
- 各軸の全文説明を8回並べず、主軸・クロス・特殊の本文と重複しない一覧にする。
