# 診断結果の詳しい説明（2026-10-26）

## 目的と適用先

持ち主の追加説明「タイトルは1つってのは、サブタイトルは何個もいらないってだけ」「結果については、昔のバージョンと同じようにしてください。ただ、文言や共感、長所等も十分に取り入れ、ダブっている文章はスマートにしたい」を反映する。

参照原稿は「ふたりの余白｜診断結果リニューアル仕様・72パターン原稿」。
https://docs.google.com/document/d/1gZmsCPczFJeuRWmF5PBNcBLNaodaeeDcl8B26hnDw3g/edit

適用先は `app/` の24問版と三択版の新しい結果表示。U46・U49 の「短い本文と閉じた回答の内訳だけ」という表示を改善する。タイトルを重複させないことと、説明を短くすることを分けて考える。

## 表示

1. 既存の絵・タイトル1つ・主結果の完成原稿。
2. 異なる情報が増える領域の補足を最大2本。各領域の完成原稿を全文で読む。小さな領域名だけを添え、キャッチコピー・一行要約・別の診断タイトルを重ねない。
3. 主結果に対応する「たとえば、こんな一言から。」と会話例を1つ。
4. 旧版と同じように、8つの軸の絵・回答の位置・選んだ数を一覧にする。各軸を開くと、完成原稿の詳しい説明と、その回答から言える範囲を読める。
5. 24問版の各軸では「普段の自分」「場面1」「場面2」の実際の選択肢も見られる。判断できない・未回答を区別する。三択版は実際に保持している回答数と比較の説明を使い、24問の場面を当てはめない。

本文は16px・行間1.8。内容のための領域ラベルと開閉操作は残すが、診断の大きな見出しは `h1.result-title` の1つ。結果画面全体を260字に切り詰めない。ホーム・シェアの短文は従来の単一出典を使う。

## 重複を避ける決まり

- 主結果の選び方と本文は今のまま。補足は同じ主軸選択順で、状態1・2・3・4から最大2領域。三択版では選択側の強さが反対側以上のものだけ。
- 主結果と補足、補足同士のテーマが同じ、または既存のテーマ群が重なる候補は飛ばす。短い補足1文と同じ領域の詳しい本文を両方出さない。
- 主結果や補足ですでに読める本文は8軸の中に再掲しない。同じページの説明へ戻るリンクと、実際の回答を見せる。
- 特殊ペア `PAIR-7B-8B` は専用の2段落と一言を維持し、補足を足さない。領域7・8はその本文を参照する。
- 方向の違いや欠損についての共通原稿も、同じ文を8回並べない。最初の説明を参照し、各領域固有の回答はそれぞれ読めるようにする。

## 維持するものと戻し方

72本の本文・16の補足／会話例・特殊ペア・保留／欠損原稿は参照資料と照合済みで、文言の差分はない。原稿を新たに自由生成しない。質問・採点・主結果の選択・保存形式・履歴・共有タイトル・相談は変更しない。追加の説明は回答と既存の原稿から表示時に組み立てる。

- `app/?rd=compact`：U46・U49 の短い結果表示。
- `app/?rc=u44`：24問版のさらに前の結果表示。
- `app/?dv=v3&rc3=old`：三択版の旧表示。

中身は `js/result_details.js`、描画は `app/js/result_details.js`、組み込みは `app/js/result4.js` と `app/js/result.js`。スタイルは `app/css/diagnose.css`。
