### 1.2 見えてきたこと（共通の気持ちと行動）

1. **夜・片手・感情が高ぶっている**：P1・P2・P4・P5。長い文や細かい選択肢は読めない。押し間違いが起きやすい
2. **「送りたい衝動」がいちばん危ない**：P1・P2。文面を見つけたらすぐコピーして送る。理由を読むのはその前でないと効かない
3. **待つのがいちばんつらい**：P1。待つ理由だけでなく「いつまで」と「待つ間にやること」がないと実行されない（[consult-mode.md](consult-mode.md) §5）
4. **相談する人は「待つ側」とは限らない**：P4 は待たせる側、P3・P2 は自分の番。入口を「返事が来ない」だけにすると取りこぼす
5. **欲しいものは人によって違う**：安心（P1）、筋（P2）、言葉（P3・P5）、断り方（P4）、段取り（P6）。カードの見出しと理由の1行目で、その人の欲しいものに先に触れる必要がある
6. **決めつけと説教に敏感**：全員。「我慢して」「落ち着いて」「考えすぎ」は避けたい言葉（[consult-answer-guide.md](consult-answer-guide.md) §2.8）
7. **初めての人は自分のタイプを知らない**：P4・P5。診断なしでも外れにくい一手が要る（決定 K3：両方のタイプで計算して外れにくい一手）

## 2. 定義：本当に解く問題

### 2.1 ペルソナごとの課題（〜には、〜が必要だ。なぜなら〜）

- P1 美咲には、**送らずに待てる根拠と期限**が必要だ。待つ期限が見えないと、不安が勝って追いLINE を送ってしまうから
- P2 結衣には、**いま動きたい気持ちを止めずに向きを変える一手**が必要だ。「落ち着いて」で止められると反発して電話してしまうから
- P3 彩花には、**読んですぐ使える自然な一言**が必要だ。考えすぎて返事が遅れ、関係を戻す機会を逃すから
- P4 真由には、**返さないことを相手に伝える短い言葉**が必要だ。黙っているのは自分を守るためなのに、相手には無視に見えるから
- P5 ひかりには、**謝る範囲と言葉**が必要だ。全部を背負う謝り方も、何もしないのも、関係を悪くするから
- P6 さきには、**一つに絞って切り出す段取り**が必要だ。繰り返しの不満が一度に出ると、話し合いが長引いて同じことが起きるから

### 2.2 問い（どうすれば〜できるか）

1. 喧嘩の夜、気持ちが高ぶっていても、**3タップ前後で**自分の状況を伝えられるようにするには？
2. 待つ側・待たせる側・自分の番・謝りたい、の**どの立場の人も最初の画面で自分の入口を見つけられる**ようにするには？
3. 文面をすぐ送りたい人に、**理由を読ませてから**送ってもらうには？
4. 「待つ」を**我慢ではなく、やることのある時間**にするには？
5. 診断していない人にも**外れにくい一手**を出し、あとで診断したくなるようにするには？
6. 危ないサインのある人を、**相手を責める気持ちにさせずに**安全の案内へ導くには？

### 2.3 ここから決める設計の原則

- **気持ち → 状況 → 一手** の順。最初に受け止め、次に状況、最後に一手
- **1画面に1つのこと**。選択肢は1画面に最大5つ（ヒックの法則）。それ以上は「ほかの場面」にまとめる
- **理由は短く、文面の前に**。1行目は気持ちを受け止める一文
- **待つ一手には必ず、期限と、手を動かすこと**
- **いつでも直せる**。答えた内容を一手の画面で見せ、1タップで直して出し直せる（決めつけない）
- **安全は最初、傾向と関係なく**

### 3.5 安全の確認（持ち主の回答で決定）

- タップの1問目に「いま、身の危険や強い怖さを感じていますか？」（ない／ある）。「ある」なら具体的なサインを選び、安全のカードへ
